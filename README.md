# AL.F.S PRIVATE SHOWROOM

알프스(AL.F.S)의 하이엔드 Three.js 3D 쇼룸입니다.
**https://alfs-showroom.vercel.app**

## 공간 구성

| 존 | 내용 | 카메라 |
| --- | --- | --- |
| 01 아틀리에 로비 | 아치 브랜드 월, 센터 테이블, 입구 | 전체 부감 |
| 02 오륜미네랄 | 1,000ml 시그니처 병(3D 라벨·유리 연단) | 클로즈업 |
| 03 하루 1.3핏 · 클린바이옴 | 30일 · 3일 박스, 클린바이옴 6병/1병 | 클로즈업 |
| 04 B2B 파트너 라운지 | 이젤 보드(10병 사전판매 → 200병 본계약), 상담 테이블 | 라운지 뷰 |

## 전담 매니저

| 존 | 담당 | 위치 |
| --- | --- | --- |
| 02 오륜미네랄 | 오륜미네랄 전담 매니저 (네이비 정장 · 올림머리) | 연단 옆 alcove |
| 03 하루 1.3핏 · 클린바이옴 | 하루 1.3핏 전담 매니저 (버건디 정장 · 단발) | 월넛 콘솔 옆 alcove |

- 매니저를 누르면(모바일은 하단 `전담 매니저 상담` 칩) 담당 존의 안내 카드가 열립니다: 구성·가격·섭취 방법·공식몰/카카오 상담.
- 카드 내용은 `src/config/staff.js` — 검증된 상품 정보만 쓰고 일반식품 고지를 유지합니다.

## 조작

- 마우스/터치 드래그로 회전, 휠·핀치로 확대
- 왼쪽(모바일 하단) 존 목록 또는 바닥 링·명패·발광면(핫스팟)을 눌러 이동
- 존 전담 매니저를 누르면 담당 존 상담 카드가 열립니다 (모바일은 하단 칩도 동일)
- 제품을 누르면 카메라가 포커스되고 상세 패널이 열립니다
- `?p=파트너코드` 로 접속하면 상단에 파트너 코드가 표시되고, 상담 신청 링크에 코드가 함께 전달됩니다

## 검증된 정보만 표시

- 가격·구성·제조원·배송비: `src/config/products.js` (출처: alfs.kr 2026-11-16 판매가 및 상품 정보)
- 모든 제품은 **건강기능식품이 아닌 일반식품**이며, 효능·질병 관련 표현은 쓰지 않습니다.
- B2B 프로그램은 10병 사전판매 / 200병 본계약 2단계 모델이며, 정확한 공급 조건은 상담에서 안내한다는 문구만 표시합니다.

## 기술

- Three.js r180 (Node 22 / Vite 7)
- `ACESFilmicToneMapping`, `PMREMGenerator` 환경 반사, `PCFSoftShadowMap`(정적 1회 베이크), 스팟 5개
- 절차적 캔버스 텍스처: 트래버틴, 플라스터, 월넛, 리넨, 황동, 제품 라벨
- 제품 3D 모델: LatheGeometry 병 + 캔버스 라벨, 라운디드 박스 + 라벨면
- UI: 순수 DOM/CSS (인트로, 존 레일, 글래스모피즘 패널, 모바일 바텀시트)
- 한글 웹폰트는 Noto Serif/Sans KR 서브셋(`public/fonts`, OFL)만 포함합니다.

npm run preview
```

## 구조

  main.js                 진입점 — 씬 조립, 카메라 이동, 클릭/호버 처리
  config/products.js      검증된 상품 데이터 · B2B 문구

    materials.js          공용 재질
    textures.js           절차적 텍스처·라벨
    architecture.js       바닥·아치 벽·천장·브랜드 월
    furniture.js          연단·콘솔·라운지·이젤 보드·핫스팟 연출

    layout.js             좌표, 존 카메라 프리셋, 핫스팟

```
