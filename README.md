# 알프스 3D 가상 쇼룸 (AL.F.S Showroom) — Phase 1

알프스(AL.F.S)의 **독립 3D 가상 쇼룸**입니다. 기존 alfs.kr은 그대로 두고, 상품 데이터와 실물 사진만 물려받아
3D 공간에서 제품을 살펴보고 · 상담 직원(3D 아바타)에게 묻고 · alfs.kr 주문으로 넘어가는 1단계(검증용) 웹앱입니다.

- 스택: **Vite + React 19 + Three.js (React Three Fiber)** — 외부 GLB 없이 절차적 지오메트리 + 실물 webp 사진 텍스처
- 빌드 산출물: JS 3청크(three 704KB / app 283KB / react 195KB), gzip 합계 약 **330KB**
- 결제·약관·환불·사업자 정보는 이 앱에 두지 않고 **alfs.kr로 연결**합니다(설계안 2장).

## 실행

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # dist/
npm run preview   # http://localhost:4173
```

## 주소 · 파트너샵(멀티테넌트)

같은 3D 공간에서 **명패 · 인사말 · 상담원 소속 · 주문 귀속 코드**만 바뀝니다.

| 주소 | 지점 |
| --- | --- |
| `/?p=hq` (기본) | 알프스 본사 |
| `/?p=sangam` | 상암 파트너샵 (예시 데이터 · 김하늘 원장) |
| `/?p=busan` | 부산 서면 파트너샵 (예시 데이터 · 박정우 원장) |

새 지점은 `src/config/partners.js`에 **한 줄(객체 하나)** 만 추가하면 됩니다.
`demo: true`인 지점은 화면에 `예시 지점` 배지가 붙습니다.

## 4개 존

| 존 | 내용 |
| --- | --- |
| ① 웰컴 로비 | 지점 간판(3D CanvasTexture) · 안내 데스크 · 상담 호출 키오스크 · 존 안내 |
| ② 오륜미네랄 존 | 중앙 원형 히어로 아일랜드(1,000ml · 220,000원) · 실물 포스터 백라이트 · 제품 사실 패널 |
| ③ 효소세상 · 데일리 케어 존 | 6종 갤러리 월 (사진 · 구성 · 가격) |
| ④ 고객 루틴 시뮬레이터 존 | 3문항 → 세트 추천 → 결과에 맞는 존으로 카메라 이동 |

## 동작

- **카메라**: 존 프리셋으로 1.25초 이징 글라이드, 드래그 회전, 휠/핀치 줌 (`src/three/Controls.jsx`)
- **이동**: 바닥 마커 클릭 · 하단 챕터 버튼(높이 56px) · 3D 키오스크
- **AI 상담 직원**: 절차적 사람 아바타(머리·몸통·팔·다리, 보행 사이클, 시선 회전, 랩 가운)
  - 바닥 동선을 순찰하다가, 클릭하거나 `상담 직원 부르기`를 누르면 고객 앞으로 걸어와 멈춰 서서 인사합니다.
  - 상담 드로어는 규칙 기반 답변 엔진(`src/lib/assistant.js`)입니다. **상품·가격·배송비는 카탈로그 값만 인용**하고,
    효능·진단·처방 표현은 쓰지 않습니다. 모르는 질문은 상담 연결로 넘깁니다.
- **상품 상세**: 3D 제품을 누르면 상세 패널 · `alfs.kr에서 주문하기` · `주문 요약 복사`(파트너 귀속 코드 포함)
- **사진 모드 없음**: 1단계에서는 3D 단일 모드입니다(느린 기기용 사진 모드는 2단계).

## 상품 데이터 (2026-11-16 alfs.kr 판매가)

`src/config/catalog.js`에 오륜미네랄 1종 + 효소세상 6종의 이름·구성·가격·배송비·사실 정보를 적었습니다.
값의 출처는 `alfs` 저장소의 `src/config/site.js` · `src/config/enzyme.js` 입니다.

- 배송비는 상품군별로 다릅니다: 오륜미네랄 3,000원 / 효소세상 4,000원, 각각 50,000원 이상 무료.
- 세트 합계·배송비는 `calcShipping()`이 두 기준을 나눠 계산합니다.

## 화면 검증용 훅 (개발 보조)

`window.__ALFS_CAM__`(카메라 좌표·글라이드 상태), `window.__ALFS_STAFF__`(상담 직원 화면 좌표·상태),
`window.__SHOWROOM_ERRORS__`(실행 중 오류 수집)은 자동 검증용으로 남겨 둔 값입니다. 운영 화면에는 보이지 않습니다.
