# AL.F.S PRIVATE SHOWROOM

알프스(AL.F.S)의 하이엔드 Three.js 3D 쇼룸입니다.
**https://alfs-showroom.vercel.app**

| 존 | 담당 | 위치 |

  - 오륜미네랄: "안녕하세요 고객님, 저는 미네랄 매니저입니다. 무엇을 도와드릴까요?"
  - 하루 1.3핏: "안녕하세요 고객님, 저는 효소세상 매니저입니다. 무엇을 도와드릴까요?"

  - 문구는 `src/config/staff.js`의 `greeting`·`faqs`만 고치면 바로 반영됩니다. 검증된 상품 정보만 쓰고 일반식품 고지를 유지합니다.

## 조작

화면에 방향키·회전 버튼은 없습니다. 손가락(터치)과 마우스만으로 둘러봅니다.

- **둘러보기**: 화면을 드래그하면 시선이 1인칭으로 부드럽게 돌아갑니다(위아래는 각도 제한). 방이 휙 돌아가지 않습니다.
- **이동**: **바닥을 톡 누르면** 그 자리로 걸어서 이동합니다(도착 지점에 금빛 링 표시). 벽·연단·테이블·키오스크는 피해 섭니다.
- **마우스 휠**: 시선 방향으로 살짝 앞뒤 이동 (제품을 공중에서 살펴볼 때는 확대/축소).
- **키보드**: `W/A/S/D` 이동, `↑↓` 앞뒤, `←→` 좌우 회전 — 화면 버튼 없이도 동작합니다.
- **카메라 안전 범위**: 어떤 조작을 해도 카메라와 시선은 쇼룸 안쪽 벽에서 1m 띄운 실내에만 머뭅니다(바닥 위·천장 아래). 벽을 뚫거나 밖으로 나가지 않습니다.
- **터치 최적화**: 캔버스에 `touch-action: none`·`overscroll-behavior: none` 을 걸어 모바일 브라우저의 당겨서 새로고침·바운스가 화면 전체를 흔들지 않습니다.
- 왼쪽(모바일 하단) **카테고리** 목록 또는 바닥 링·명패·발광면(핫스팟)을 눌러 존을 이동합니다.
- **제품을 누르면** 주문 페이지로 바로 가지 않고, 제품이 **공중으로 떠올라** 360° 회전·확대로 살펴보는 화면이 열립니다.
  - 탭: `상세설명 보기`(후면 설명서 이미지 자리 포함) · `활용법`(희석·섭취·보관 안내)
  - `구매 페이지 열기`는 패널 안에서 직접 눌러야 열립니다. `내려놓기`로 원래 진열대로 돌아갑니다.
- **전담 매니저**를 누르면 인사말과 예상질문 10개가 있는 대화 패널이 열립니다.
- **05 루틴관리** 키오스크를 누르면 아침·점심·저녁 루틴 카드와 `alfs.kr/diagnosis` 연결 패널이 열립니다.
- **파트너샵**(카테고리 `SHOP`)을 누르면 B2B 파트너 라운지로 이동하며 10병 사전판매 → 200병 본계약 상담 패널이 열립니다.
- `?p=파트너코드` 로 접속하면 상단에 파트너 코드가 표시되고, 상담 신청 링크에 코드가 함께 전달됩니다

## 검증된 정보만 표시

- 가격·구성·제조원·배송비: `src/config/products.js` (출처: alfs.kr 2026-11-16 판매가 및 상품 정보)
- 상품 후면 설명서 이미지는 `products.js`의 `MANUAL_SLOT` 문구 자리에 준비되면 넣습니다(현재 '추가 예정' 자리 표시).
- 모든 제품은 **건강기능식품이 아닌 일반식품**이며, 효능·질병 관련 표현은 쓰지 않습니다.
- B2B 프로그램은 10병 사전판매 / 200병 본계약 2단계 모델이며, 정확한 공급 조건은 상담에서 안내한다는 문구만 표시합니다.

## 기술

- Three.js r180 (Node 22 / Vite 7)
- `ACESFilmicToneMapping`, `PMREMGenerator` 환경 반사, `PCFSoftShadowMap`(정적 1회 베이크), 스팟 5개
- 절차적 캔버스 텍스처: 트래버틴, 플라스터, 월넛, 리넨, 황동, 제품 라벨
- 제품 3D 모델: LatheGeometry 병 + 캔버스 라벨, 라운디드 박스 + 라벨면
- UI: 순수 DOM/CSS (인트로, 존 레일, 글래스모피즘 패널, 모바일 바텀시트)
- 한글 웹폰트는 Noto Serif/Sans KR 서브셋(`public/fonts`, OFL)만 포함합니다.
